# Explain (in-page chrome)

Recreates the **content-script surfaces** — what the extension injects on top of any web page or PDF.

- `mark-bubble` — the green pill that floats above a selection. Press = compresses, hover = brightens. Hero gradient (`#1a6b4a → #2fa373`).
- `explain-card` — bottom-right floating card with source row, quote, three-depth pill (Brief / Detailed / Deep), AI body (with streaming cursor), auto-extracted tags, and an action row (Save + pin/copy/more icon buttons).
- `toast` — bottom-center save-confirmation with `Undo` (auto-dismiss 3s).

Open `index.html` for the on-page composition.
