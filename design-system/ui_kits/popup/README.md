# Popup (400×600)

Recreates `LumiNote/popup/popup.html` — the mini notebook that opens when you click the toolbar icon.

**Frame** — fixed 400×600, mounted at the chrome popup position. Glass topbar over the mint app gradient. Three-tab nav (Today / Calendar / Moodboards), search, vertical list of memory cards, footer with the primary "Open full notebook" CTA + quota chip.

**Components in this kit**
- Topbar with gradient logo tile, title, ghost icon buttons (new, settings)
- Segmented tabs (active = bottom-border + primary color)
- Search input — small variant (32px tall vs the regular 48px)
- `mem-card` — memory atom with source row + quote + (optional) AI gloss + tags
- Day-section label
- Footer button row with primary CTA + quota chip

Open `index.html` to view.
