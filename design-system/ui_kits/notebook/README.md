# Notebook + Moodboard + Agent

Recreates the full-page notebook (`LumiNote/notebook/notebook.html`) — the canonical "all of LumiNote in one window" view.

Three columns:
1. **Sidebar** — brand, top-level nav (Today / Calendar / Search), moodboard list, account chip with plan + quota.
2. **Moodboard canvas** — dotted background, multi-select state on the focused card, glass cards with optional hero image / quote / tags. Toolbar over the top-right (select / pan / add / export).
3. **Agent rail** — sliding right panel; chat with inline tool-call receipts (`search_memories`, `read_memory`, `add_moodboard_card`) and a Composer at the bottom.

This kit covers four of the eight surfaces simultaneously (Notebook, Moodboard, Agent panel, partial Settings via the account chip).
