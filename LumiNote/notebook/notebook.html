MCP Bridge

Connect AI Agents to LumiNote

LumiNote is a shared data center for humans and AI. You mark memories from the browser; AI agents read and write the same Memory Blocks via MCP (Model Context Protocol) to search, create, update, and resume from the exact web or PDF location.

What is MCP + LumiNote

LumiNote is the shared data layer. Humans mark memories from the browser; AI agents read and write the same Memory Blocks through MCP. Both sides operate on an identical schema — there is no separate human format or agent format.

How to connect

Install the luminote-mcp-server to bridge any MCP-compatible AI agent (Claude, OpenClaw, etc.) to this extension. The MCP server communicates with LumiNote through a local WebSocket bridge.

1
Install the MCP server 
npm install -g luminote-mcp-server
2
Add to your AI agent config 
{
  "mcpServers": {
    "luminote": {
      "command": "npx",
      "args": ["-y", "luminote-mcp-server"]
    }
  }
}
3
Keep this page open

The extension auto-connects to the MCP server's WebSocket bridge. This page must be open for the bridge to stay alive.

Write API — OpenClaw → LumiNote

OpenClaw can create and manage Memory Blocks using the same schema.

Create a memory

Add a new Memory Block. id is auto-generated if omitted.

chrome.runtime.sendMessage({
  type: "CREATE_MEMORY",
  block: {
    "term": "Attention Is All You Need",
    "entryType": "text",
    "sourceKind": "web",
    "sourceUrl": "https://arxiv.org/abs/1706.03762",
    "sourceTitle": "Attention Is All You Need — arXiv",
    "note": "Foundational transformer paper.",
    "aiSummary": "Introduces the Transformer model.",
    "context": "We propose a new simple network architecture...",
    "tags": ["transformers", "attention"]
  }
}, response => console.log(response))
// → { ok: true, id: "lr_1744027620000_abc1234" }

Update a memory

Patch note, aiSummary, or tags on an existing block.

chrome.runtime.sendMessage({
  type: "UPDATE_MEMORY",
  id: "lr_1234567890_abc1234",
  fields: {
    "note": "Revised: also relevant for vision transformers (ViT).",
    "tags": ["transformers", "attention", "deep-learning", "vision"]
  }
}, response => console.log(response))
// → { ok: true }

Delete a memory

Permanently remove a Memory Block from the library.

chrome.runtime.sendMessage({
  type: "DELETE_MEMORY",
  id: "lr_1234567890_abc1234"
}, response => console.log(response))
// → { ok: true }

Read API — OpenClaw ← LumiNote

Command templates for read access.

Search memories

Find Memory Blocks by term, note content, source kind, or domain.

chrome.runtime.sendMessage({
  type: "SEARCH_MEMORIES",
  query: "transformer",
  filters: { sourceKind: "web", limit: 10 }
}, response => console.log(response))
// → { ok: true, results: [...], total: 3 }

Read one memory

Retrieve the full Memory Block including note, AI summary, anchor, and locator.

chrome.runtime.sendMessage({
  type: "GET_MEMORY",
  id: "lr_1234567890_abc1234"
}, response => console.log(response))
// → { ok: true, memory: { id, term, note, ... } }

Open original source

Reopen the saved page or PDF at the saved page number.

chrome.runtime.sendMessage({
  type: "OPEN_MEMORY",
  id: "lr_1234567890_abc1234"
}, response => console.log(response))
// → { ok: true, sourceUrl, sourceTitle, ... }
// Also opens the source in a new tab

Moodboard API — OpenClaw ↔ Boards

AI agents can read, create, and manage Moodboard sessions (infinite canvas boards) and place Memory Blocks as spatial cards.

List sessions

List all Moodboard sessions with name, timestamps, and card count.

chrome.runtime.sendMessage({
  type: "LIST_MOODBOARD_SESSIONS"
}, response => console.log(response))
// → { ok: true, sessions: [{ id, name, createdAt, updatedAt, cardCount }] }

Get session details

Retrieve full session including all cards with their associated Memory Block data.

chrome.runtime.sendMessage({
  type: "GET_MOODBOARD_SESSION",
  id: "mb_1706000000000_xyz9876"
}, response => console.log(response))
// → { ok: true, session: { id, name, viewport, cards: [{ cardId, entryId, x, y, entry: {...} }] } }

Create session

Create a new empty Moodboard with an optional name.

chrome.runtime.sendMessage({
  type: "CREATE_MOODBOARD_SESSION",
  name: "Research: Transformer Papers"
}, response => console.log(response))
// → { ok: true, session: { id: "mb_...", name, cards: [], ... } }

Update session

Rename a board or update its viewport (pan/zoom state).

chrome.runtime.sendMessage({
  type: "UPDATE_MOODBOARD_SESSION",
  id: "mb_1706000000000_xyz9876",
  fields: { name: "Renamed Board" }
}, response => console.log(response))
// → { ok: true }

Delete session

Permanently delete a Moodboard session and all card placements.

chrome.runtime.sendMessage({
  type: "DELETE_MOODBOARD_SESSION",
  id: "mb_1706000000000_xyz9876"
}, response => console.log(response))
// → { ok: true }

Add card to board

Place a Memory Block on the canvas at a specific position.

chrome.runtime.sendMessage({
  type: "ADD_MOODBOARD_CARD",
  sessionId: "mb_1706000000000_xyz9876",
  entryId: "lr_1234567890_abc1234",
  x: 200,
  y: 150
}, response => console.log(response))
// → { ok: true, card: { cardId: "mbc_...", entryId, x, y } }

Remove card from board

Remove a card placement (does not delete the underlying Memory Block).

chrome.runtime.sendMessage({
  type: "REMOVE_MOODBOARD_CARD",
  sessionId: "mb_1706000000000_xyz9876",
  cardId: "mbc_1706000001000_abc1234"
}, response => console.log(response))
// → { ok: true }

Message API

All APIs are available via chrome.runtime.sendMessage(). Use the message type as the type field.

CREATE_MEMORY

Write

Add a new Memory Block following the LumiNote schema. id and timestamp are auto-generated. All other fields follow the same schema used by human marks.

UPDATE_MEMORY

Write

Patch mutable fields: term, note, aiSummary, tags. Immutable fields (sourceUrl, sourceAnchor, timestamp) are ignored.

DELETE_MEMORY

Write

Permanently remove a Memory Block. Reflected immediately in the human-facing Memory Library.

SEARCH_MEMORIES

Read

Search across term, note, aiSummary, and context. Filter by sourceKind, entryType, domain, or date range.

GET_MEMORY

Read

Return the full Memory Block: note, aiSummary, sourceAnchor, sourceLocator, and image metadata where applicable.

OPEN_MEMORY

Read

Return sourceUrl, sourceTitle, sourcePage (PDF), and resume metadata. Opens the source in a new tab.

LIST_MOODBOARD_SESSIONS

Read

List all Moodboard sessions. Returns id, name, createdAt, updatedAt, and cardCount.

GET_MOODBOARD_SESSION

Read

Retrieve full session with all cards enriched with their Memory Block data (term, note, aiSummary, etc.).

CREATE_MOODBOARD_SESSION

Write

Create a new empty Moodboard session. Accepts optional name field.

UPDATE_MOODBOARD_SESSION

Write

Update session name or viewport (pan/zoom). Requires id and fields object.

DELETE_MOODBOARD_SESSION

Write

Permanently delete a Moodboard session and all its card placements.

ADD_MOODBOARD_CARD

Write

Place a Memory Block on a Moodboard canvas. Requires sessionId, entryId, and optional x/y coordinates.

REMOVE_MOODBOARD_CARD

Write

Remove a card from a Moodboard session. Does not delete the underlying Memory Block.
